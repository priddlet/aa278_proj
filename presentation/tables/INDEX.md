# Presentation tables

Generated by `python scripts/build_presentation_assets.py`. Each navigation pipeline has its own subdirectory.

| Predict mode | Directory | EKF time update |
|--------------|-----------|-----------------|
| **Truth-velocity predict** | `truth_velocity/` | Truth velocity between updates |
| **Filter CV predict** | `filter_predict/` | Filter CV predict only |
| **Filter dynamics predict** | `filter_dynamics/` | Filter dynamics (RK45 + STM, HW2 Q) |

## Per-pipeline files

- `main_summary.md` — policy comparison (km)
- `main_policy_summary.csv` — aggregated stats
- `main_trials.csv` — per-trial rows
- `pulsar_sweep.md` / `.csv` — MSP count sensitivity; includes |b| timing (m) on PR epochs
- `toa_sweep.md` / `.csv` — TOA σ sensitivity; includes |b| timing (m) on PR epochs
