# Presentation tables

Generated by `python scripts/build_presentation_assets.py`. Each navigation pipeline has its own subdirectory.

| Predict mode | Directory | EKF time update |
|--------------|-----------|-----------------|
| **Truth-velocity predict** | `truth_velocity/` | Truth velocity between updates |
| **Filter CV predict** | `filter_predict/` | Filter CV predict only |
| **Filter dynamics predict** | `filter_dynamics/` | RK45 + STM (Tier A); HW2-style σ_acc process noise |

## Per-pipeline files

- `main_summary.md` — policy comparison (km)
- `main_policy_summary.csv` — aggregated stats
- `main_trials.csv` — per-trial rows
- `pulsar_sweep.md` / `.csv` — MSP count sensitivity (full build)
- `toa_sweep.md` / `.csv` — TOA σ sensitivity (full build)

## Disturbances (J2 + SRP)

Optional HW2 P3 perturbations on the **shared truth arc** (all predict modes see the same reference orbit):

```bash
python scripts/build_presentation_assets.py --disturbed-dynamics --pipelines nav
```

Or `MonteCarloConfig(include_disturbances=True)`.

## Q tuning (process noise)

Run separately (not part of default presentation build):

```bash
python scripts/sweep_process_noise.py --filter-predict --trials 10
```

Writes `presentation/tables/filter_predict/q_sweep.md` and `q_sweep.csv` with **constant CWNA** rows and **gravity-scaled** rows (`q_a(r) ≈ (scale·GM/r²)²`, periapsis-aware).
